# アルテマブラスター サイコロ カンペ (絶ケフカ P3)

絶妖星乱舞 P3「アルテマブラスター」のサイコロ立ち位置を可視化する OverlayPlugin (ACT) 用オーバーレイ。
`magic/missing` と同じ構造（`index.html` + `src/*.js` + `styles.css`）。

## しくみ

ケフカの**連続突入**から **1回目の突入先(D)** と **回転(時計/反時計)** を自動判定し、
サイコロ **1〜8 全員分**の安置（フィールドマーカー間の八角形の頂点）を描画する。
自キャラの番号マーカーを検出すると自分のスポットをハイライトする。

立ち位置は `angle(N) = D + s×(22.5° + (N−1)×45°)`（s = 反時計 +1 / 時計 −1）。
ログの能力ID・マーカーで判定するので、ログのファイル名やゾーン番号には依存しない。

## 追加

OverlayPlugin → カスタムオーバーレイ → URL にこの `index.html` を `file:///` で指定。
サイズを正方形に調整。戦闘終了（ワイプ/撃破）で自動リセット。

## 設定

[src/ultimablaster.js](src/ultimablaster.js) 冒頭の `CONFIG`：

- `waymarks` … フィールドマーカー配置（既定はこのPT配置。数字1〜4は左90°回転）
- `diceIconMap` … 頭マーカー icon → サイコロ番号（既定 1〜8）
- `sound` / `debug` / `demo` … 通知音 / 診断バナー / デモ表示

## テスト

- `node test/harness.js` … ロジック検証
- `test/replay.html` … ブラウザで過去ログ/内蔵シナリオを流して確認（ゲーム不要）
