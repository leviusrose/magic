# P4 カンペ 2段版 (絶ケフカ ネオエクスデス & カオス)

絶妖星乱舞 P4 の「どこに行けばいいか」を小さいアリーナ図 8 枚に分けて並べる
OverlayPlugin (ACT) 用オーバーレイ。**`magic/dmp4` の 2 段版**で、中身は同じ・並べ方だけが違う
（4 枚 × 2 段）。どちらか気に入ったほうを使う。`magic/ultimablaster` と同じ構造。

`magic/dmp4` との差分は 2 箇所だけ:

- [src/dmp4.js](src/dmp4.js) の `PANEL_ROWS`（`1` → `2`）
- [styles.css](styles.css) の `#dm-grid`（flex 1 行 → grid 4 列 × 2 段）

## しくみ

処理ごとに小さいアリーナ図を作り、**時系列で 4 枚 × 2 段**に並べる。
**上段が ①〜④（前半）／下段が ⑤〜⑧（後半）** で、攻略マクロの ┃ の切れ目と同じ分かれ方。
図の大きさは**高さに合わせて**決まる（1 段の高さ = グリッド高さの半分）。
**並びは固定**で、終わった図は薄くなるだけ（位置は動かない）。いま処理する図は枠が光る。

アリーナの表現（床のグラデ・八方位の線・北の N・英字＝丸／数字＝四角のマーカー）は
`magic/ultimablaster` と同じ。図は常に北が上・マーカーも実配置のままなので、頭の中で回さなくていい。

図には ①〜⑧ の番号が付いていて、下のバーが解決までの進み具合（100% で着弾）。

| # | 図 | 出るもの |
| --- | --- | --- |
| ① | 無の氾濫 | 行く色（紫/青）だけを 1 枚の色板で。GC3 のデバフが揃った時点で確定 |
| ② | 早 雷水 | 自分の行き先（1人受け=東西 / 頭割り=南北）。止/動 は自分マーカーの中と一言の横 |
| ③ | 視線1 | 見ない / 見る。中央の視線持ちと自分の向き |
| ④ | 炎 | タケノコ（中央の小さい円範囲）/ 中央（ドーナツ）。範囲の形だけ |
| ⑤ | 遅 雷水 | ② と同じ |
| ⑥ | 視線2 | ③ と同じ |
| ⑦ | 直線 / 扇 | マジックチャージ後の単発 2 発（もりもりサンダガ 77.5s＝直線 → ひろげるブリザガ 95.5s＝扇）。位置ではなく 踏む/踏まない が答えなので図ではなく 2 行 |
| ⑧ | つなみ | ④ と同じ |

図の中では**自分の行き先が主役**（黄色のマーカー＋中心からの点線）で、全員の候補は小さい暗い点。
「何をするか」の言葉は図の下の一言が持ち、文字は箱に自動フィットするので大きさを変えても潰れない。
canvas は縦を「見出し / アリーナ / 一言 / バー」の 4 帯に割っていて、
一番下のバー帯には何も描かないのでプログレスバーと文字は重ならない（`draw.js` の `geom()` と
`styles.css` の `.p-bar` が対応している）。

- **真偽** はボスに付く隠しステータス `808` の count（カオス/ネオエクスデスで別値）で確定する。
  ボス別に保持するので、グランドクロスと ほのお/つなみ の詠唱順が入れ替わっても影響しない。
- **早/遅** はデバフの残り時間で決まる（フォーク/水圧縮/加速度が 51s・36s なら早、76s・61s なら遅。
  呪詛の叫声は 60s が視線1、69s が視線2）。各図に残り秒も出る。
- **立ち位置はマップ基準**。TH は 北と西、DPS は 南と東で、南北が 3人頭割り・東西が 1人受け（早/遅 とも同じ）。
  全部マップ基準なのでボスの位置は使わない（図にも描かない）。
- **無の氾濫** の行く色は GC3 のデバフだけで決まる（死の超越＝傷の色そのまま / アラガンフィールド＝逆の色）。
  無の氾濫そのものの真偽では色を反転させない（cactbot は反転させる実装だが、このPTの処理法に合わせている。
  合わなければ `computeLaser()` の 1 行を戻す）。左右は詠唱まで分からないので既定では出さない。
- **⑦ の単発 2 発** はマジックチャージが合図。予兆が本当なら本物なので踏まない、嘘なら予兆に入る。
  詠唱（サンダガ `C5DE` / ブリザガ `BA95`）が来ていない行は「?」のまま、過ぎた行は薄くして残す。
  残り秒は「次に来るほう」、プログレスバーは「遅いほう（扇）」で伸ばす。
  マジックアウトで溜めた 2 発が同時に来るぶんは、この 2 発で分かるのでカンペには出さない。
- 自分に関係する図は色が変わり、3 秒前に音が鳴る。処理が済んだ図は薄くなる。
  戦闘終了（ワイプ/撃破）で自動リセットして全部戻る。

## 追加

OverlayPlugin → カスタムオーバーレイ → URL にこの `index.html` を `file:///` で指定。
4 枚 × 2 段なので**やや小さめの塊**（目安 440×290）に調整。図 1 枚の幅は「1 段の高さ × 0.76」で
自動的に決まるので、高さを変えれば全体が追随する。

## 設定

[src/dmp4.js](src/dmp4.js) 冒頭の `CONFIG`：

- `positions` … 頭割り・1人受け の立ち位置（北からの時計回り deg。北 0 / 東 90 / 南 180 / 西 270）
- `baitAt` … タケノコを捨てる場所（既定 `'center'` = 中央固定）
- `showLaserSide` … 無の氾濫で左右も出すか（既定 `false` = 色だけ）
- `waymarks` … フィールドマーカー配置（既定はこのPT配置。数字 1〜4 は左 90° 回転）
- `role` … `'auto'`（自分のジョブから TH/DPS を自動判定）/ `'th'` / `'dps'`。
  ジョブは `PartyChanged` と `03` 行（job は16進）の両方から引くので、到着順に関係なく決まる
- `labels` … 表示文言。使っているマクロの言い回しに合わせて差し替える
- `sound` / `debug` / `demo` … 通知音 / 診断バナー / デモ表示

## ブラウザで試す

- **[P4 シミュレータ](../p4-sim/)** … このオーバーレイをそのまま動かして、真偽・自分のデバフ・傷の色を
  ランダムに引き直しながらイメトレできるページ。敵の詠唱・着弾・デバフ付与・自分が動く瞬間を
  cactbot 準拠のタイムラインで流す。1段/2段はその場で切り替え可。

## テスト

- `node test/harness.js` … ロジック検証（描画も fake canvas で通す）
- `test/replay.html` … ブラウザで内蔵シナリオ／実ログを流して確認（ゲーム不要）
- `test/samples.html` … 起こりうる図のパターンを一覧表示（本体の `src/draw.js` をそのまま使う）
- `test/samples.png` … 上を画像に落としたもの（[samples.png](test/samples.png)）

図を直したら画像も撮り直す（ヘッドレス Chrome）：

```
chrome --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2   --window-size=1180,2700 --screenshot=test/samples.png <test/samples.html の file:/// URL>
```

`--window-size` の高さがページより短いと下が切れるので、セルを増やしたら伸ばす。

## 注意

能力 ID・ステータス ID は cactbot の絶妖星乱舞データ由来で、**まだ実ログで裏取りできていない**。
初回は `CONFIG.debug = true` で回して、上部バナーとコンソールの `[dmp4]` 行を実際の挙動と突き合わせること。
