# アルテマブラスター サイコロ カンペ (絶ケフカ P3)

**絶妖星乱舞(絶ケフカ)P3「アルテマブラスター」**のサイコロ(番号)立ち位置を可視化する
OverlayPlugin (ACT) 用オーバーレイ。`magic/missing` と同じ構造（`index.html` + `src/*.js` + `styles.css`）。

ケフカの**連続突入（観察フェーズ）**を ACT ログから読み取り、

- **1回目の突入先**（＝起点 D）
- **回転方向**（時計回り / 反時計回り）

を自動判定して、**サイコロ 1〜8 の立ち位置**をフィールドマーカー基準の八角図に描画する。
自キャラに付いた**番号マーカー**を検出すると、行き先スポットをハイライト＋通知音で知らせる。

## ギミックのしくみ（実装根拠）

| 段階 | 内容 |
|---|---|
| 観察 | ケフカ分身が**八方位のエッジから中心を貫いて**約 2 秒間隔で 8 回突入。1周する向き（時計/反時計）と**1回目の突入先**を見る |
| 番号 | 全員の頭に**サイコロ番号 1〜8** が付く |
| 解決 | 番号順にレーザー（アルテマブラスター）。**安置＝隣り合う突入線の中間**（フィールドマーカー間）に、番号ごとに散開する |

**立ち位置の数式**（フィールド中心を原点、北からの時計回り角、実ログ 10 バースト＋各種攻略マクロで検証）：

```
D = 1回目の突入先の方角（8方位のどれか）
s = ケフカが反時計回りなら +1 ／ 時計回りなら −1   （番号はケフカの回転と逆回りに増える）
angle(サイコロ N) = ( D + s × (22.5° + (N−1)×45°) ) mod 360
```

→ 突入先 **D は サイコロ 1（回転の逆側）と サイコロ 8（回転側）に挟まれる**。安置は
フィールドマーカーとマーカーの**中間**（22.5°ずらし）の八角形の頂点。

> **フィールドマーカー配置**は既定でこのPT配置：**A/B/C/D＝北/東/南/西**、
> **数字 1〜4 は標準から左（反時計）に90°回転**して **1=北西・2=北東・3=南東・4=南西**。
> 別配置の静地は [src/ultimablaster.js](src/ultimablaster.js) の `CONFIG.waymarks` の
> `angle`（北からの時計回り deg）を書き換える。

## 使うログ（実ログ `Network_30203_*.log` で確定）

| ログ行 | 用途 |
|---|---|
| `22 … BAE3 アルテマブラスター` | **観察フェーズの突入**。分身のソース座標（fields 40/41）＝突入元エッジ。1回目→**D**、2回目との差→**回転** |
| `27 … <icon>` | **サイコロ番号マーカー**（icon `0150`-`0153` / `01B5`-`01B8` の 8 種）。自分の番号を確定 |
| `21 … BAE4 アルテマブラスター` | 解決フェーズのレーザー（この時点で解決） |
| `02` ChangePrimaryPlayer / `ChangePrimaryPlayer` イベント | **自キャラ ID** の確定（dottimer と同じ） |
| `260` InCombat flag=0 | **戦闘終了（ワイプ/撃破）で即リセット**（何度ワイプしても待機に戻る） |
| `01` ChangeZone | ゾーン移動（再入場）でリセット |

> 番号マーカーの `icon → サイコロ番号` の対応は既定で連番（`0150`-`0153`=1-4 /
> `01B5`-`01B8`=5-8）。**サイコロ位置(1〜8)は D と回転から常に正しく描かれる**ので、
> 対応が万一ズレていても**頭の数字を見て同じ番号のスポットへ**行けば安全。ズレていたら
> `CONFIG.diceIconMap` を直す（`CONFIG.debug=true` で検出 icon を確認できる）。

## OverlayPlugin への追加

1. ACT → OverlayPlugin → 新規 → **カスタムオーバーレイ**を追加
2. URL にこの `index.html` を指定（例: `file:///C:/Users/&lt;user&gt;/GitLab/magic/ultimablaster/index.html`）
3. 位置・サイズは「背景を白にする」にチェック → Width/Height/X/Y で正方形に合わせる → チェックを外す
4. 動作確認は `CONFIG.debug = true` で Reload → 上部バナーに `own:… D:… rot:… self:…` が出る

## 表示

- 外周に**フィールドマーカー A〜D / 1〜4**（標準配置）。中を貫く薄線＝**突入線（危険）**。
- **赤い矢印＋「1回目」**＝ 1回目の突入先 D。青い弧＝回転方向。
- 青丸 1〜8 ＝各サイコロの安置（マーカー間）。**自分の番号は黄色**でパルス＋中心から線。
- HUD 下段：`1回目→B(東) ／ 時計回り` と `あなた 3番 → 4/A の間`。

## 設定

[src/ultimablaster.js](src/ultimablaster.js) 冒頭の `CONFIG` を編集する。

```js
var CONFIG = {
  diceIconMap: { '0150':1,'0151':2,'0152':3,'0153':4, '01B5':5,'01B6':6,'01B7':7,'01B8':8 },
  waymarks: [ {label:'A',angle:0,...}, {label:'1',angle:45,...}, ... ],  // 標準リング
  resetAfterSec: 30,     // バースト終了後の自動リセット
  sound: true, soundFile: '', soundVolume: 0.7,
  ownNameHint: '',       // 戦闘中起動時のフォールバック (フルネーム)
  showStatus: false, debug: false, demo: false,
};
```

### 表示・音だけ試す（デモモード）

`CONFIG.demo = true` → Reload。`D=東・時計回り・自分3番` のサンプルが常時表示される。確認後 `false` に戻す。

## トラブルシュート

| 見えるもの | 状態 | 対処 |
|---|---|---|
| バナーすら出ない | ページ未読込 | URL を `file:///…/index.html`（forward slash）で。右クリック→Reload。枠を 300×300 以上に |
| `API:detached` | OverlayPlugin API 未検出 | 「カスタム」オーバーレイで追加しているか |
| `log:0` | ログが来ない | ACT の Network parse が緑か / 該当ゾーンにいるか |
| `own:?` | 自キャラ未確定 | `CONFIG.ownNameHint` にフルネーム → Reload（任意行動 1 回で確定） |
| 番号スポットは合うが自分ハイライトがズレる | `diceIconMap` の対応違い | `debug` で `self:N(icon)` を確認し `diceIconMap` を修正 |
