# P4 カンペ (絶ケフカ ネオエクスデス & カオス)

絶妖星乱舞 P4 の「どこに行けばいいか」を小さいアリーナ図 8 枚に分けて並べる
OverlayPlugin (ACT) 用オーバーレイ。`magic/ultimablaster` と同じ構造。

## しくみ

処理ごとに小さいアリーナ図を作り、**時系列で横 1 行**に並べる。図の大きさは**高さに合わせて**決まり、
横に入りきらないぶんは右で切れる。**終わった図は消えて残りが左へスライドしてくる**ので、
いま見るべき図が常に左端に来る。並びは攻略マクロ（早水雷｜視線1｜炎 ┃ 遅水雷｜視線2｜つなみ）と同じ順。

アリーナの表現（床のグラデ・八方位の線・北の N・英字＝丸／数字＝四角のマーカー）は
`magic/ultimablaster` と同じ。図は常に北が上・マーカーも実配置のままなので、頭の中で回さなくていい。

図には ①〜⑧ の番号が付いていて、下のバーが解決までの進み具合（100% でその図が消えて左に詰まる）。

| # | 図 | 出るもの |
| --- | --- | --- |
| ① | 無の氾濫 | 入るレーザー。マップは描かず 紫/青 を左右に並べて、入るほうを明るく塗る |
| ② | 早 雷水 | 自分の行き先（1人受け=東西 / 頭割り=南北）。隅に 止/動 |
| ③ | 視線1 | 見ない / 見る。中央の視線持ちと自分の向き |
| ④ | 炎 | タケノコ（中央の小さい円範囲）/ 中央（ドーナツ）。範囲の形だけ |
| ⑤ | 遅 雷水 | ② と同じ |
| ⑥ | 視線2 | ③ と同じ |
| ⑦ | マジックアウト | 位置ではなく真偽が答えなので、図ではなく 扇 / 直線 を 踏む/踏まない の 2 行 |
| ⑧ | つなみ | ④ と同じ |

図の中では**自分の行き先が主役**（黄色のマーカー＋中心からの点線）で、全員の候補は小さい暗い点。
「何をするか」の言葉は図の下の一言が持ち、文字は箱に自動フィットするので大きさを変えても潰れない。
canvas は縦を「見出し / アリーナ / 一言 / バー」の 4 帯に割っていて、
一番下のバー帯には何も描かないのでプログレスバーと文字は重ならない（`draw.js` の `geom()` と
`styles.css` の `.p-bar` が対応している）。

- **真偽** はボスに付く隠しステータス `808` の count（カオス/ネオエクスデスで別値）で確定する。
  ボス別に保持するので、グランドクロスと ほのお/つなみ の詠唱順が入れ替わっても影響しない。
- **早/遅** はデバフの残り時間で決まる（フォーク/水圧縮/加速度が 51s・36s なら早、76s・61s なら遅。
  呪詛の叫声は 60s が視線1、69s が視線2）。各図に残り秒も出る。
- **立ち位置はマップ基準**。TH は 北と西、DPS は 南と東で、南北が 3人頭割り・東西が 1人受け（早/遅 とも同じ）。
  全部マップ基準なのでボスの位置は使わない（図にも描かない）。
- **マジックアウト** は マジックチャージ時の予兆と、出た瞬間の予兆が一致していれば「その予兆は本当」。
- 自分に関係する図は色が変わり、3 秒前に音が鳴る。戦闘終了（ワイプ/撃破）で自動リセット。

## 追加

OverlayPlugin → カスタムオーバーレイ → URL にこの `index.html` を `file:///` で指定。
図 8 枚が横 1 行に並ぶので横長（目安 900×150）に調整。図 1 枚の幅は高さの 0.76 倍で自動的に決まるので、
高さを変えれば全体が追随する（900×150 なら 8 枚ちょうど収まる）。入りきらないぶんは右で切れて、
終わった図が消えると左に詰まってくる。

## 設定

[src/dmp4.js](src/dmp4.js) 冒頭の `CONFIG`：

- `positions` … 頭割り・1人受け の立ち位置（北からの時計回り deg。北 0 / 東 90 / 南 180 / 西 270）
- `baitAt` … タケノコを捨てる場所（既定 `'center'` = 中央固定）
- `waymarks` … フィールドマーカー配置（既定はこのPT配置。数字 1〜4 は左 90° 回転）
- `role` … `'auto'`（自分のジョブから TH/DPS を自動判定）/ `'th'` / `'dps'`。
  ジョブは `PartyChanged` と `03` 行（job は16進）の両方から引くので、到着順に関係なく決まる
- `labels` … 表示文言。使っているマクロの言い回しに合わせて差し替える
- `sound` / `debug` / `demo` … 通知音 / 診断バナー / デモ表示

## テスト

- `node test/harness.js` … ロジック検証（描画も fake canvas で通す）
- `test/replay.html` … ブラウザで内蔵シナリオ／実ログを流して確認（ゲーム不要）
- `test/samples.html` … 起こりうる図のパターンを一覧表示（本体の `src/draw.js` をそのまま使う）

## 注意

能力 ID・ステータス ID は cactbot の絶妖星乱舞データ由来で、**まだ実ログで裏取りできていない**。
初回は `CONFIG.debug = true` で回して、上部バナーとコンソールの `[dmp4]` 行を実際の挙動と突き合わせること。
