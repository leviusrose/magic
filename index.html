magic

FFXIV / ACT OverlayPlugin 用の自作オーバーレイ置き場。

ブラウザで開けるもの

  • 絶妖星乱舞 P4 カンペ シミュレータイメトレ用

    P4 のカンペオーバーレイを実際に動かして、真偽・自分のデバフ・傷の色をランダムに引き直しながら イメトレできるページ。敵の詠唱・着弾・デバフ付与・自分が動く瞬間をタイムラインで表示。1段/2段の切り替え付き。

  • P4 カンペ 図サンプル（1段版）

    ①〜⑧ の図が取りうるパターンの一覧。

  • P4 カンペ リプレイテスター

    内蔵シナリオ、または ACT のネットログを読み込んで再生する。

オーバーレイ本体（OverlayPlugin に file:/// で登録して使う）

  • dmp4

    絶妖星乱舞 P4 カンペ。図 8 枚を横 1 行に並べる版。

  • dmp42

    同じものを 4 枚 × 2 段に並べる版。

  • ultimablaster

    P3 アルテマブラスターのサイコロ立ち位置。

  • dottimer

    DoT の残り時間。

  • countdown

    カウントダウン。

各プラグインの詳細は GitHub 側の README を参照。 github.com/leviusrose/magic
